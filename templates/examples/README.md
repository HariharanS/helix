# Template Examples

This folder contains illustrative examples of Helix prompt and artifact shapes.

## Rules

- Examples must reflect the current Helix philosophy
- Examples should be tech-agnostic by default
- Stack-specific examples do not belong here unless they are clearly isolated in a named subfolder and still actively maintained
- If an example drifts from the live agent or skill behavior, delete or refresh it

## Current Examples

- `jam.prompt.md` — simple prompt entry example

For canonical reusable structure, prefer the templates in the parent `templates/` directory over the examples in this folder.
